# ESP Rotating Colors and Gradient Green Screen Effects

🎨 **Advanced Sprite-Based Visual Effects for ESP Microcontrollers**

This repository contains code that enables you to create stunning visual effects on ESP microcontrollers by rendering sprites with advanced color manipulation, gradient effects, and green screen techniques.

## ✨ Features

### Core Capabilities
- **Sprite Rendering**: Load and display custom sprites onto your ESP display
- **Rotating Colors**: Create dynamic, rotating color effects across sprites
- **Gradient Effects**: Apply smooth color gradients to enhance visual appeal
- **Green Screen Effects**: Implement chromakey/green screen functionality to overlay sprites with transparency

### Technical Highlights
- **Flexible Image Support**: Work with multiple image formats including JPG
- **Character Overlay**: Overlay text characters with sprite graphics seamlessly
- **Customizable Sprites**: Paint anything you can load into a sprite with custom visual effects
- **Lightweight Implementation**: Optimized for resource-constrained ESP microcontroller environments

## 🚀 Getting Started

### Prerequisites
- ESP microcontroller (ESP32/ESP8266 or compatible)
- Compatible display module
- Image assets (JPG, PNG, or other supported formats)

### Basic Usage
1. Load your sprite images (JPG or other formats)
2. Configure color rotation and gradient parameters
3. Apply green screen effects as needed
4. Render to your ESP display
